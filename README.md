# Aujunpeak VN v3.0 Preview

Ban preview cua app iOS Aujunpeak VN duoc viet bang SwiftUI.

## Diem moi
- Dang nhap preview bang Google / GitHub UI (khong can API)
- Tab Tong quan duoc lam lai voi hero `Aujunpeak Wropych VN` va anh nen do nguoi dung cung cap
- Tab Game hien thi game that tu App Store va hieu ung Boost
- Tab Function co log lenh, switch va bo cuc data layout
- Tab Tin nhan gom Chat Cong dong va Chat voi Admin
- Tab Tai khoan duoc toi gian va hien thi thong tin thiet bi

## Luu y
- Dang nhap Google / GitHub trong ban nay la preview UI, chua tich hop OAuth that
- Cac switch Boost / Aimlock / Optimizer chi la giao dien xem truoc, khong can thiep truc tiep vao Free Fire hoac he thong iOS
- Viec mo game se uu tien deep link neu co, neu khong se mo lien ket App Store cua game

## Build
Dung GitHub Actions hoac Xcode de build nhu cac ban truoc.
